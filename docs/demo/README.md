# Demo playlist

`playlist.m3u` is a small playlist for trying the app without an IPTV provider. App Review uses it, and so do the App Store screenshots. To add it, open Playlists in the app. Under Add Provider, choose M3U Playlist, pick URL where the app offers URL or File, and enter:

```
https://raw.githubusercontent.com/MaxMB15/MaxVideoPlayer/main/docs/demo/playlist.m3u
```

Every entry is a stream its owner publishes for anyone to play. The three test streams show up under Live, and the four Blender films under Movies, because their entries carry `tvg-type="movie"`.

| Entry | Served by | Terms |
| --- | --- | --- |
| Apple HLS example | Apple's HLS examples for developers | Published by Apple for testing players |
| Akamai live test | Akamai's public HLS test stream | Public test stream |
| Unified Streaming live test | Unified Streaming's public demo server | Public test stream |
| Big Buck Bunny | Mux's public HLS test streams | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| Elephants Dream | download.blender.org | [CC BY 2.5](https://creativecommons.org/licenses/by/2.5/) |
| Sintel | THEOplayer's public demo content | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| Tears of Steel | Unified Streaming's public demo server | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |

Each movie's picture is a still from the film, taken from Wikimedia Commons under the film's license. The credits below list each one. The app shows movies in wide cards, so a still fits better than a poster.

These servers belong to other people, and an entry can stop working when they move things. If one does, swap in another public test stream and check that the new one allows anyone to play it.
